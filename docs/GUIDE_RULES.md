# 부기 캐릭터 가이드북 규정 (부산시 소통캐릭터 부기 베이직 가이드북 26.04)

원본: `ref/bugi-guidebook.pdf` (60쪽, 이미지 PDF). **캐릭터·그림·색·동작을 바꾸기 전에 이 문서와 해당 쪽을 먼저 확인한다.** 어긋나는 변경은 하지 않거나, 해야 하면 사용자에게 경고한 뒤 한다.

## 반드시 지키는 규정 (어기면 경고)
| 항목 | 규정 | 쪽 | 코드 |
|---|---|---|---|
| 형태 | 서양배 몸통 + 머리 위 빨간 안경 + 검은 지그재그 머리카락 + 노란 부리(가운데 가로줄) + 눈은 검은 점 두 개. 비율·위치 임의 변경 금지 | p6~11, p17 | `Rig.cs` |
| 비율 | 눈 지름 1D 기준: 눈 간격 3D(중심), 부리 너비 약 3.6D, 안경 전체 너비 약 5.5D | 규격 시트 | `BugiGuide.Check` |
| 선 | 윤곽선은 K100 검정, 키의 약 1%로 통일. 얇은 선·굵기가 다른 선 금지 | p17 라인규정 | `Rig.Draw` 의 `ow` |
| 색 | 전용색상만: 빨강 `0 100 100 0`(안경·동백꽃), 노랑 `0 15 100 0`(**부리와 다리 같은 노랑**), 초록 `80 0 80 0`(동백잎), 검정 `0 0 0 100`, 흰색(몸·날개·밑창). 주황 부리·다리 금지 | p12, p17 컬러규정 | `BugiGuide` |
| 날개 | 흰 지느러미 + 검은 끝, 몸 윤곽에서 이어짐 | p7, p17 | `Rig.DrawWing` |
| 신발 | 검은 운동화, 흰 밑창·흰 끈, 동백꽃 무늬 | p7, p17 | `Rig.DrawShoe` |
| 안경 | 빨간 얇은 테 + 오른쪽 스마트 글래스 돌출부(좌우 반전해도 오른쪽) | p6, 규격 시트 2 | `Rig.DrawGlasses` |

| 흑백 | 부득이할 때 흰 바탕 + 검은 윤곽선으로 표현 | p14 | — |
| 표정 | 슬픔·윙크·놀람·먹방·흐뭇·평온·화남·수면 (눈 점/줄/></^/∪). 이 밖의 임의 표정 금지 | p16 | `EyeStyle` |
| 로고타입 | boogi / 부기 로고는 변형·재조합 금지, 최소 크기 규정 | p22~25 | `LogoArt` |
| 저작권 | 출처표시 · 비상업적 이용만 · **변형 등 2차적 저작물 작성 금지**. 상업적·변형 이용은 부산광역시와 사전 협의 | p2 | README 하단 |

배경색(p13): 노랑 `0 25 100 0`, 빨강 `0 100 100 25`, 민트 `70 0 50 0`, 파랑 `100 70 0 0`. 보조색(p22): 짙은 빨강 `0 100 100 60`, 주황 `0 51 100 0`.

## 가이드북에 없는 기존 요소 (참고)
곡괭이질(참조 그림 4), 근무복(참조 3D 그림), 스마트 안경 검색 화면(홀로), 볼 발그레·눈 위 눈썹·어질어질 눈은 사용자 참조 그림에서 온 것이며 가이드북 표정(p16)에는 없다. 새로 만들지 않고 유지하되, 변경하려면 먼저 확인한다.

## 점검 방법
```
powershell -ExecutionPolicy Bypass -File build.ps1      # 빌드 후 자동으로 아래 두 점검을 돌려 경고(노란색)를 보여 준다
bugi.exe --guide-test [폴더]                             # 색·선 굵기·비율 점검 → guide_check.txt (경고가 있으면 종료 코드 2)
```
`Rig*.cs` 의 숫자 색 리터럴 줄 끝에는 출처를 적는다: `//g:p31`(가이드북 쪽수) · `//fx`(표정 효과) · `//ref`(가이드북에 없는 참조 그림). 빠지면 빌드가 경고한다.
